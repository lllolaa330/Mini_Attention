# OS 阵列内 SCNA 的 PV 排程

[PE 电路图（SVG，可编辑）](os_scope_pe.svg) · [矢量 PDF](os_scope_pe.pdf) · [PNG](os_scope_pe.png)

图按 SCOPE 论文图 9 的四联格式重绘。蓝色 Standard 表示 OS 基础电路；当前双条带实例使用 128 个 Left 与 128 个 Right。`reg1` 向东转发 A，`reg3` 向南转发 B，`reg2` 保存 OS 部分和。图中的 × 和 + 合起来是一条只舍入一次的 FP16 FMA。矩阵乘只写 `reg2`；指数模式左 PE 写 `regZ`（仿射结果）并独立用 `regX` 向下转发 x，右 PE 写 `regU`（指数部分和）。右 PE 的常量偏置 `b_h` 向左邻静态连线，`w_h` 固定在左 PE。为与论文的画法一致，图中省略了时钟、局部写使能、valid 和帧标签。

默认设计采用两个 8 行条带、16 路指数输入。以本帧首个 QK 乘加的上升沿为第 0 拍，PV 从第 **120** 拍开始；无停顿时每 **52** 拍启动下一帧 QK。寄存器在表中所列上升沿后可读。

| 第 0 行 | 上升沿 |
|---|---:|
| 收到最后一个缩放分数，写入最终行最大值 | 31 |
| 16 路分批送入减去行最大值的分数 | 32–54 |
| 收到最后一个指数 | 62 |
| 四级求和、两级除法、整行 P 写回 | 63–66、67–68、69 |
| 首个 PV 乘加；PE[0,0] 写入 Y[0,0] | 120；135 |

第 i 行各时刻顺延 i 拍。条带 g（0 或 1）内第 p 对 PE（0 至 7）在第 `32+i+8g+2p` 拍接收该行的一个分数。每个指数只算一次；分列缓存先到的结果，最后到的通道可直接进入求和树，同时保留各分子供除法。

稳态时，PE[r,c] 的局部相位为 `(t−r−c) mod 52`。第 0–15 拍算当前帧 QK，第 16–31 拍算早两帧的 PV，第 32–47 拍算当前帧指数，余 4 拍空闲。此排程配置双份 Q/K、三份 V、双份 P，每次取数按帧号选槽。若所需输入未就绪或输出缓冲已满，设计要求阵列、归约流水与帧标签同步暂停；输入端可继续填充空槽。

用 `python3 docs/os_scna_pe/check_schedule.py` 可复核 8 帧的设计级排程。实现在 [OS-SCOPE 顶层](../../rtl/os_scope_attention_fp16.sv) 和 [双条带阵列](../../rtl/os_scope_array.sv)。在仓库根目录运行 `make os-scope` 可逐位核验 RTL 输出并读回实际对角线使能。实测 12 个全速帧的 11 个相邻启动间隔均为 52 拍；第 0 行 P 在本帧 QK 启动后第 69 个逻辑沿写回，首个 PV 乘加在第 120 个逻辑沿执行。表里的 t 是推进沿，外部输入至首/末结果握手的冷启动延迟另计，为 169/199 个时钟周期。[逐沿检查](../../results/os_scope_verilator_20261118/os-scope/mesh_checks.json) · [带背压波形](../../results/os_scope_verified_wave_20261118/os-scope/attention.vcd)
